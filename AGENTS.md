# go-roark

Unofficial Go client for the Roark API, generated from the OpenAPI document Roark publishes. If you only want to use the client from an agent, read [.agents/skills/go-roark/SKILL.md](.agents/skills/go-roark/SKILL.md) instead; this file is about changing the code.

## Architecture

One generated package, `roark`, at the module root, driven by `gen.go`:

`scripts/fetch-spec.sh` downloads `https://api.roark.ai/doc` to `api/openapi.json`, then `scripts/patch-spec.sh` writes `api/openapi.fixed.json`, then oapi-codegen with `config.yaml` writes `client.gen.go`.

The patch converts OpenAPI 3.1 schema features to OpenAPI 3.0.3: nullable type arrays, null union branches, singleton unions, `const`, schema examples arrays and numeric exclusive bounds. It retains every path and operation.

## Stack

- Go 1.26.9.
- oapi-codegen, pinned as a `tool` dependency in `go.mod`.
- Runtime: `github.com/oapi-codegen/runtime`.

## Layout

- `gen.go`, `config.yaml`, `client.gen.go`: the package.
- `client_test.go`, `example_test.go`: tests, including the README example.
- `scripts/`: spec download, schema patches, lint and security scan scripts.
- `api/`: the downloaded spec, gitignored.
- `vendor/`: committed, regenerated by `make dep`.

## Dev workflow

Everything runs in the `Dockerfile.dev` image. You need Docker and Make.

```bash
make dep       # go mod tidy + go mod vendor
make generate  # download the spec and regenerate
make lint      # shellcheck, shfmt, go fix, golangci-lint
make test      # go test -race
make sec       # gitleaks, govulncheck, semgrep
```

## Project-specific landmines

- The published document is OpenAPI 3.1.0. oapi-codegen's OpenAPI 3.0 reader needs `scripts/patch-spec.sh` before generation. The source remains untouched in `api/openapi.json`.
- A null-only union branch becomes `nullable: true`. A remaining single branch is collapsed so oapi-codegen does not emit undefined `N0` accessors. Nullable references use `allOf` because the OpenAPI 3.0 reader ignores `nullable` beside `$ref`.
- `const` becomes a one-value `enum`; schema `examples` uses the first example. Numeric `exclusiveMinimum` and `exclusiveMaximum` become bounds with boolean exclusive flags.
- Keep `number` mapped to `float64` in `config.yaml`. Prefixing enum values avoids collisions in the large generated package.
- Keep `skip-prune: true` in `config.yaml`. The default path-based model pruning drops component types used only by top-level webhook unions, leaving undefined types in generated code.
- Bearer authentication is supplied by a request editor. User-scoped credentials can select a project with `X-Roark-Project-Id`; project-scoped keys are bound to one project.
- `GetV1ProjectsWithResponse` lists accessible projects. Method names are normalized from the spec's operation IDs, including hyphenated IDs.
- HTTP error status codes do not produce transport errors. Check the response status and expected decoded status field.
- `make generate` always downloads the current spec, so it can change the client even when nothing here changed. Review the generated diff before committing it.
- `.github/workflows/regen.yml` regenerates the client every day and releases the result. When the checks fail, Claude edits the repository to fix them, but a fix may not touch the paths listed under `fix_protected_paths` in that workflow: the workflows, the Makefile, `AGENTS.md`, `.agents/rules/`, the lint, security and spec download scripts and their configs. A problem that needs a change there fails the run and needs a manual fix.
